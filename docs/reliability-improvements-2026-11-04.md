# MindFlow 13.2.1 保存与生命周期加固

本轮重点解决部分模块化带来的契约漂移和退出保存问题。候选阶段完成隔离 Zotero 10.0.7 的 51 项回归与 3 项重启验证；
正式发布元数据与下载说明见 [13.2.1 发布说明](releases/v13.2.1.md)。

## 已修复的行为

1. 带关系线的导图使用编辑器实际的 `fromId` / `toId` 字段，存储、大纲导出和附件归档共用一个宿主校验器。旧模块的 `fromNodeId` / `toNodeId` 校验会错误拒绝正常导图。
2. 退出等待直接读取存储模块的真实队列，并重复核对关闭保存、文件写入及附件归档三个队列，直到队列身份稳定。排队操作在入口冻结参数，调用方之后修改 `force` 或 `expectedRevision` 不会改变已排队事务。
3. 关闭保存失败会解除该快照的去重标记，相同内容可以重试；版本冲突继续保留脱离原条目关联的恢复副本。
4. 停用时先捕获编辑器、取消 AI，再等待持久化、关闭插件工作台和清理注册。迟到的标签页恢复不能重新创建工作台，迟到的大纲导出不能再写笔记。
5. 大纲导出在异步读取后重新检查父条目、附件、目标笔记及插件生命周期，拦截回收站、只读、改换父项等状态；读取导图同样经过结构校验。笔记写入权限不再错误依赖附件文件写入权限。
6. 侧栏保留 Zotero 原生折叠状态，显式点击 MindFlow 侧栏入口时展开目标卡片；本机宿主导航只滚动、不展开的行为由独立 `item-pane-visibility.js` 补齐。监听器在销毁或停用时按精确文档解绑；初始化动画帧不能在销毁后重新激活面板。
7. 编辑后立即显示“待保存”，本地写入完成、正在归档时显示“本地已保存 · 归档中”。设置模板的静态文字全部通过 Fluent 提供，候选版本徽标带明确状态。

## 模块边界与工程验证

- 移除入口中的存储、大纲导出与校验器重复实现；关闭与队列协调提取为 `workspace-lifecycle.js`。
- 本轮持久化领域模块受 360 行守卫约束。其余历史大文件尚未完成整体拆分，不能据此宣称全仓库达标。
- `npm test`：宿主回归、前端逻辑、包策略和标签语法校验。
- `npm run build:bundle`：TypeScript 检查、生产前端构建及脚本语法检查。
- `package-xpi.py --candidate`：包内文件与工作区逐文件校验、可复现 ZIP 元数据及 SHA-256/SHA-512；不会修改发布源。
- `scripts/native-regression.js`：仅在隔离 Zotero profile 执行。侧栏用例等待真实的展开状态后再断言，保留展开与非空检查。
