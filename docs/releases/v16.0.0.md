# Zotero MindFlow 16.0.0

Zotero MindFlow 正式发布 **16.0.0** 大版本，标志着全系统一大版本（Zotero Flow Unified Major Release 16.0.0）协同确立。

## 🌟 核心升级与特性

1. **统一全系大版本号**：跃升至 16.0.0，与 Zotero Flow 家族其余六大插件保持完全一致的版本号与契约；
2. **规范 Gecko 153 文件选择器特权接口**：移除 `Components.classes` / `Components.interfaces` 历史过时用法，全面拥抱原生特权全局 `Cc` / `Ci`，提供更加安全平滑的文件系统交互；
3. **架构守卫与 360 行红线**：全仓 100% 恪守 360 行上限约束（0 债务），所有前端 React 组件及宿主 TypeScript 模块全量受控；
4. **双向 Fluent 本地化中英双语严格对称**：全面板 100% Fluent `data-l10n-id` 驱动，零硬编码；
5. **完整自动化测试验证**：架构守卫、宿主行为测试、XPI 构建测试及前端单元测试全部通过。
