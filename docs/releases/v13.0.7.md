## 🌟 核心更新与逻辑完善细节

### 1. 节点条目跳转交互动效与加载状态反馈（Interactive Loading State）
- 节点卡片外链/DOI 按钮在触发本地数据库定位时，按钮立即切换为平滑旋转的加载指示器（Spinner），向用户提供即时、明确的操作响应状态；
- 加入点击防抖与并发保护，防止用户在检索期间重复点击导致多次触发；
- 若本地文库未找到对应条目，系统在检索结束后自动平滑回退并在系统默认浏览器中打开文献官方页面。

### 2. 全格式 DOI 识别与大小写兼容（Universal DOI Protocol Compatibility）
- `safeExternalUrl` 升级为大小写不敏感的前缀与空格智能剥离算法，全面兼容大写 `DOI:`、小写 `doi:`、带空格的 `DOI: 10.xxxx/...` 及裸 DOI 文本；
- 解决右侧属性面板链接输入框在粘贴 `DOI: 10.1038/...` 格式时可能出现的误报拦截问题。

### 3. Zotero Extra 字段与节点备注 DOI 级联检索（Extra Field DOI Support）
- `searchItemByDoi` 扩展为三级级联检索方案（`DOI is` -> `DOI contains` -> `extra contains`），完美兼容 BibTeX、arXiv、预印本及第三方文献导入工具将 DOI 存放在 Zotero `extra` 字段的文献条目；
- 支持从节点的备注（Note）字段中提取文献 DOI，实现即使标题未包含 DOI、也能准确识别文献并完成文库定位。

### 4. 导图归档父条目 DOI 深度解析（DOI Parent Resolution for Archiving）
- 宿主 `_saveMindMapToItem` 归档接口扩展：当导图父条目引用为 DOI 格式时，自动调用 `searchItemByDoi` 检索并绑定真实文献条目；
- 导图大纲笔记与 `.mindflow` 附件将精准归档入该文献条目的子树中，避免回退创建未关联的独立导图。

### 5. 右键菜单与属性面板双向联动全面统一
- 节点右键菜单及右侧属性面板全面支持从节点的链接、正文及备注中智能解析文献目标，确保“在 Zotero 文库中定位”与“阅读 PDF”在所有操作路径下表现一致。
