## 🌟 核心更新与逻辑优化细节

### 1. Markdown 导入协议完整性与 Round-trip 保障
- 在 `source/src/services/io/exporter.ts` 的 `importFromMarkdown` 中，将链接提取正则从 `(?:https?|zotero)` 拓展为兼容 `(?:https?|zotero|file|attachment)`；
- 解决用户节点关联本地 PDF 路径（如 `file:///...`）或内部附件协议时，Markdown 导出后无法在导入时恢复为节点 `link` 属性的单向断裂缺陷，实现本地文献附件与内部链接的 100% 完整往返。

### 2. 离线交互 HTML（Interactive HTML）触控与多端漫游手势
- 在 `exportToInteractiveHTML` 生成的独立自包含 HTML 中，新增针对触摸屏设备的 `touchstart`、`touchmove`、`touchend` 与 `touchcancel` 事件监听；
- 用户在触控笔记本（Surface 等）、iPad 或移动设备上离线打开导图时，支持手指丝滑平移拖拽与无缝浏览，显著提升离线交付件在不同终端的一致性体验。

### 3. 研读预设（Research Presets）UUID 生成环境安全回退
- 在 `researchPresets.ts` 中增强随机 ID 生成的健壮性，当运行于非安全上下文或早期测试环境中缺少原生 `crypto.randomUUID` 时，自动平滑回退至高熵随机串与时间戳拼接算法，防止异常阻断预设保存。

### 4. 审查文档索引（docs/README.md）时序与双语深度对齐
- 修正中文与英文索引中 `10.0.5` ~ `10.0.7` 错写为升序的时序颠倒缺陷，统一为严格倒序 SemVer（`10.0.7` → `10.0.6` → `10.0.5`）；
- 在英文索引中补齐遗漏的两份重要深度审查报告（`2026-10-16 插件全流程审查与优化建议` 与 `2026-10-07 深度逻辑审查与修复`），实现中英文两套索引结构与条目的严格 1:1 双语映射。
