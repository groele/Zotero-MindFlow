**发布日期**：2026-11-05

## 🌟 变更与加固概述

Zotero MindFlow v14.0.1 紧跟 v14.0.0 架构重构，针对全链路数据处理逻辑、多窗口上下文隔离、TypeScript 类型契约一致性与构建安全守卫进行了深度检查与彻底加固。

---

## 🚀 核心改进与修复

### 1. 多窗口状态隔离与上下文安全选区 (`Multi-Window Isolation`)
- 修复在多主窗口或独立阅读器窗口下侧边栏刷新回退至全局 `Zotero.getMainWindow()` 导致选区串读的问题；
- 新增 `resolveContextSelection(win, doc)` 窗口上下文选区解析器，严格根据当前触发窗口优先获取 `win.ZoteroPane?.getSelectedItems()` 或阅读器当前条目 `Zotero.Items.get(win.ZoteroReader.itemID)`；
- 侧边栏刷新防抖定时器（`scheduleItemPaneRefresh` / `cancelItemPaneRefresh`）全面隔离至当前窗口局部作用域（`win.setTimeout` / `win.clearTimeout`），杜绝跨窗口竞态取消。

### 2. 宿主与 TypeScript 源码 100% 对齐与严格类型契约
- 补齐 `src/host/storage.ts` 对并发已处理标识追踪（`processedId`、`clearProcessed`）及历史 `Zotero.Prefs` 清理的严格类型契约声明；
- 补齐 `src/host/bridge.ts` 对目标窗口所有权校验（`openTargetIdentity`、`openActionMessage`）的强类型约束；
- `npm run typecheck:host`（`tsc --noEmit -p tsconfig.json`）静态类型检查 0 错误通过。

### 3. 数据处理逻辑链路深度审计与只读安全加固
- 全面审计 8 条核心数据处理链路：
  1. 工作区存储 CAS 乐观并发与 `.tmp` 原子落盘校验；
  2. Zotero 条目与 `.mindflow` 附件唯一关联与双向映射；
  3. 大纲笔记导出（`exportAttachmentToNote`）全生命周期权限核验（父条目存在、`isEditable()`、`!deleted` 及事务回滚）；
  4. IPC `postMessage` 双向消息源与白名单通道；
  5. AI 智能研读模型接入与免密管道；
  6. WebDAV HTTPS 云端增量容灾同步；
  7. 离线交互 HTML、SVG、PNG、Markdown、OPML 多模态导出转换；
  8. 右侧文献侧栏原生 Web Component 响应式渲染。

### 4. 构建流水线持久化单文件守卫 (`<= 360 行`)
- 在 `scripts/build-source.mjs` 中新增持久化核心模块行数硬门禁，确保 `storage.js`、`workspace-lifecycle.js`、`note-sync.js`、`item-pane-visibility.js` 单文件均严格不超过 360 行；
- 构建期强校验 `manifest.json` 与各配置文件版本号绝对同步。
