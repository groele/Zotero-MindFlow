# Zotero MindFlow 16.2.1

Zotero MindFlow 正式发布 **16.2.1** 版本，彻底重构并优化论文研读弹窗的逻辑与视觉组织，修复读取范围与焦点引导词的底层冲突，去除冗余重复提示，增强卡片依赖禁用联动。

## 🌟 核心改进与修复

1. **界面组织重构与去重（UI Cleanup & Deduplication）**：
   - **清除重复的报错与警示信息**：彻底修复在未勾选资料时，来源区域与底部同时弹出两处相同报错文字的堆叠问题；
   - **消除冗余的“切换全文”引导**：精简复选框内与卡片底部的重复按钮，统一为单一紧凑的横幅引导；
   - **清理焦点卡片下方冗余的长文本堆砌**：移除重复出现在卡片底部的模板规则与冗长段落，统一精炼为简洁的外观提示行。

2. **宿主层读取范围与侧重引导深度解耦（Host Guide Decoupling）**：
   - 修复 v16.2.0 中因 `focus` 兜底为 `all` 导致宿主层 `readingGuide` 被 `focusGuide` 覆盖的严重问题；
   - 现在 `readingGuide` 严格绑定实际读取范围（`abstract` / `key-sections` / `full`），永不被覆盖，防止大模型在仅读摘要时产生“全文综合分析”的实验细节幻觉；
   - `focusGuide` 作为可选叠加层，仅在用户选定特定侧重且具备所需全文资料时生效。

3. **焦点卡片依赖置灰与前置校验（Focus Availability Guard）**：
   - 当用户处于仅读摘要且未发送 PDF 正文时，“方法与实验设计”、“讨论与深度机理”、“数据与关键发现”等必须依赖正文的卡片自动置灰禁用；
   - 卡片呈现虚线边框与半透明状态，悬浮显示“需全文 PDF / 核心章节”提示，坚决阻止非法参数组合向宿主与大模型发送；
   - 点击侧重卡片时纯粹更新 `focus` 侧重字段，不再粗暴覆盖用户手写的 `customPrompt` 自定义提示词。

4. **学术预设精简与纯粹解耦（Scenario Presets Decoupling）**：
   - 将内置预设库瘦身为 4 个纯粹的学术场景预设：`通用系统精读`、`组会汇报脉络精讲`、`严谨证据链与复现验证`、`实验复现与参数提取`；
   - 章节侧重（方法/讨论/数据/结论/摘要）彻底交由独立的“AI 重点分析侧重”卡片与宿主引导词负责，消除双重指令冗余。

5. **严格的工程质量保障**：
   - 全库 185 个 TypeScript/TSX 源码文件 100% 恪守单文件 360 行上限约束（0 违规、0 债务）；
   - 全链路版本号严格对齐 `16.2.1`，中英双语 Fluent 目录 174 键完全对称；
   - 16 项架构守卫、116 项宿主测试、40 项导图逻辑 + 8 项预设工作台 + 23 项数据完整性测试全部 PASS（共 71 项前端测试，0 失败）。
