## 🌟 核心更新与修复细节

### 1. 快捷键与交互行为代码级校准
- 严格对照 `App.tsx` 键盘事件处理逻辑，移除未实现的 `F2`，修正 `Space` 为进入节点快速编辑态；明确分支折叠展开为节点微交互把手点击；
- 完整补齐真实可用快捷键：`Shift + Enter`（在上方插入同级节点）、`Ctrl + S`（快速落盘并触发 Zotero 附件归档）、`Ctrl + D`（快速创建节点副本）、`Ctrl + Z` / `Ctrl + Y`（撤销与重做）、`F5` / `Alt + P`（全屏演示模式）、`Ctrl + 1` / `Ctrl + 0`（画布置中与 100% 缩放重置）以及方向键（`↑` `↓` `←` `→`）平滑导航。

### 2. 品牌体系与规范标识全面对齐
- 严格遵循 `docs/brand/README-TEMPLATE.md` 与工作区规范，恢复标准系列标识行 `Zotero Flow Series · 知识组织`（英文版对应 `Zotero Flow Series · Knowledge`）；
- 丰富特性副标题，保留完整的标准化 Shields.io 徽标矩阵。

### 3. 设置面板与侧栏功能真实对齐
- 准确还原 `preferences.xhtml` 中真实呈现的三大核心分组（文献与工作台、AI 研究与数据保存、导图编辑与快捷键）；
- 校正工具栏停靠位置枚举为 `top`（顶部）与 `bottom`（底部），校正窗口模式为 `tab`（选项卡）与 `window`（独立窗口），移除不存在的“PDF 批注抓取阈值”；
- 真实对齐侧栏 ItemPane 的 5 项核心动作：打开/一键生成导图、PDF 并排小窗、打开关联 PDF、多模态导图导入（MindFlow/JSON/Markdown/OPML）与新建独立空白导图。

### 4. 8 套内置学术研读模板完整呈现
- 严格对照 `research-templates.json`，在文档中真实收录内置 8 大研读模板：论文精读（按发现组织）、完整研究解析、速读概览、证据链、实验复现、理论与计算、机理辨析、综述与对比。

### 5. 审查文档索引（docs/README.md）历史证据精准化
- 还原 12.7.0（兼容上限跃升 12.*、侧栏防抖、PDF 异步回退）与 12.7.1（ItemPane 侧栏 UI 重构）的真实历史发布内容。
