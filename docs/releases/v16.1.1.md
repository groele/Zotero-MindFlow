# Zotero MindFlow 16.1.1

Zotero MindFlow 正式发布 **16.1.1** 版本，全面加固数据流与生命周期防线，彻底消除空选区及状态穿透导致的旧条目导图残留隐患，重构优化 AI 研究弹窗信息架构与资料来源交互。

## 🌟 核心升级与加固

1. **全链路数据流与状态生命周期加固**：
   - 彻底修复未选择文献或选择非文献条目时，新建导图误复用上一个条目导图的逻辑穿透隐患；
   - 宿主层 `openTargetIdentity()` 对空选区与新建模式生成全局隔离身份，切断标签页误复用通道；
   - 前端 `useAppHostMessaging` 与 `useAppFoundation` 建立防御性解析，意图明确但数据不齐备时强制生成独立空白导图；
   - 左侧工作台删除当前活动导图后即刻重置内存引用，避免后台定时自动保存复活“僵尸”副本；
   - 存储层在删除文档时同步清理 `ACTIVE_DOC_ID` 悬空指针。

2. **AI 论文研究弹窗信息架构深度优化**：
   - **文献与资产卡片居首**：首屏清晰呈现文献题目、已检测到的 PDF 附件、摘要、笔记与批注数，消除信息倒置；
   - **资料来源与读取模式紧密联动**：在“本次发送的资料”中为每一项提供明确的禁用原因说明（如聚焦摘要模式未载入正文、文献暂无笔记等）；
   - **一键快捷切换 PDF 全文**：在“PDF 正文 / 节选”旁常驻一键切换全文与核心章节通道，无需繁琐翻找下拉菜单；
   - **提示词与预设折叠收拢**：将高级补充提示词与预设管理收拢为原生折叠抽屉，首屏干净清爽，兼顾新手极速分析与专业研究者进阶定制；
   - **紧凑响应式双列布局**：分析框架与大模型选择采用双列网格排版，大幅减少纵向滚动疲劳。

3. **架构守护与代码质量红线**：
   - 全库 182 个 TypeScript/TSX 源码文件 100% 恪守单文件 360 行上限约束（0 债务）；
   - 全链路版本号严格对齐，中英双语 Fluent 目录 174 键完全对称。

4. **完整工程与发布验证**：
   - 类型检查、16 项架构守卫、宿主测试、40 项导图逻辑 + 7 项预设 + 23 项数据完整性测试全部 PASS。
