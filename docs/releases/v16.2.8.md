# Zotero MindFlow 16.2.8

Zotero MindFlow 正式发布 **16.2.8** 版本，围绕「力导向知识图谱与思维流动」重新设计并上线 **「彗尾星云图谱」（Tapered Galaxy Flow）** 品牌与全套插件图标，全面提升从 16px 侧栏 / 工具栏到高分屏附加组件管理器的识别度与明暗主题适应性。

## 🌟 视觉与工程改进

1. **全新「彗尾星云图谱」全端统一视觉标识**：
   - 替换 `chrome/content/icons/` 与 `chrome/content/assets/icons/` 下的全彩矢量主标（`icon.svg`、`mindflow.svg`、`mindflow-toolbar.svg`、`toolbar-mindflow.svg`）、24px 设置页徽标（`icon-accent.svg`）及 16px `context-fill` 侧栏单色图谱图标（`sidebar-tab-mindflow.svg`）；
   - 重绘 `icon16.png` ~ `icon512.png` 全尺寸位图（`16/32/48px` 采用无投影锐利轮廓，`64px` 及以上保留立体层次，并为节点增加高光描边以防 Zotero 蓝底选中态融边）；
   - 同步更新 React 工作台组件 [MindFlowMark.tsx](../../source/src/components/brand/MindFlowMark.tsx)，通过 `useId()` 隔离渐变与滤镜 ID，避免工作台顶栏与欢迎弹窗同屏渲染时发生 ID 冲突。

2. **全链路构建与校验通过**：
   - 双端 TypeScript 检查、16 项架构守卫、124 项宿主模拟测试、10 项发布包自检、标签校验自检与全部 5 组前端测试均通过（0 失败、0 跳过）；
   - `package-xpi.py --update-feeds` 完成 `zotero-mindflow-16.2.8.xpi` 确定性打包及双份更新源哈希同步。
