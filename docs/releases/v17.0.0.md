# Zotero MindFlow 17.0.0

Zotero MindFlow 正式发布 **17.0.0** 统一大版本，对宿主生命周期（`AbortController` 窗口/标签页/独立窗体/ItemPane 清理）、React 工作台防泄漏清理、`aiHelpers` 模块解耦及双向链接/图谱渲染测试进行系统加固，并与 Zotero Flow 全家桶同步升级至 `v17.0.0`。

## 🌟 工程与可靠性升级

1. **宿主与工作台全生命周期收敛**：
   - 新增宿主窗口、标签页、独立窗体与 ItemPane 面板 `AbortController` 清理链路，以及 7 处 React 组件（`CommandPalette`、`WelcomeModal`、`NodeCardContent`、`CanvasSearch`、`LeftWorkbench`、`PropertySidebarRelationshipFields`、`useAppAiResearch`）的事件与定时器注销保障；
   - 抽取 `src/host/aiHelpers.ts` 收敛 `src/host/entry/` 模块规模。

2. **回归测试扩展与统一发布验证**：
   - 宿主测试扩展至 130 项（新增 `scripts/host-tests/host-runtime-08.test.mjs`），新增前端图谱/双链测试 `source/tests/test-graph-and-links.ts` 与生命周期清理测试 `source/tests/test-lifecycle-cleanup.ts`；
   - 双端 TypeScript 检查、架构守卫、`package-xpi.py --update-feeds`、`test:package` 与 `test:tags` 校验全量通过。
