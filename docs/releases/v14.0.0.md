# Zotero MindFlow v14.0.0 发布说明

**发布日期**：2026-11-05  
**目标版本**：v14.0.0 (Major Release)  
**兼容范围**：Zotero 10.0 至 12.* (`strict_min_version: 10.0`, `strict_max_version: 12.*`)  
**Add-on ID**：`mindflow@groele.org`

## 🌟 重大架构演进概述

Zotero MindFlow v14.0.0 是一次里程碑式的现代架构大版本重构。彻底告别了过往「`bootstrap.js` + `chrome.manifest` 覆盖式注册 + 宿主单体脚本 (`index.js`) + `source/` 独立 Vite 前端」的双层割裂架构，全面迁移至面向 Zotero 10 ~ 12 现代架构（Gecko 153+ 标准）的 **esbuild + TypeScript 统一工程流水线**。

---

## 🚀 核心变更与特性

### 1. 前后端共享类型契约层 (`src/common/types/`)
- 抽象统一领域模型：节点树（`MindMapNode`）、关系线（`RelationshipLink`）、导图文档（`MindMapDocument`）、收集箱（`InboxItem`）；
- 收敛宿主与导图画布间的 20+ 项 IPC 消息契约与 Payload 强类型约束；
- 彻底解决前后端 IPC 通信字段断层与隐式 bug 隐患。

### 2. 宿主巨石领域解耦与 TypeScript 模块化 (`src/host/`)
将原宿主逻辑彻底解耦为 7 个强类型领域模块：
- `constants.ts`：全局常量、数据结构合法性与安全边界校验；
- `storage.ts`：CAS 乐观锁并发控制、`.tmp` 原子写入、`.bak` 备份自愈与回读字节校验；
- `workspaceLifecycle.ts`：窗口关闭状态快照捕获与 `AsyncShutdown` 阻断器排空队列；
- `noteSync.ts`：纯本地大纲笔记生成与只读/回收站安全拦截守卫；
- `itemPane.ts`：Zotero 10 `<info-box>` Web Component 自定义 Section 交互与只读态展示；
- `itemPaneVisibility.ts`：侧边栏原生折叠状态同步与事件管理；
- `bridge.ts`：Iframe 宿主所有权解析与双向消息安全路由。

### 3. 统一构建流水线 (`scripts/build-source.mjs`)
- 单一脚本统筹全局类型检查（`tsc --noEmit`）、React 画布构建（Vite + React 19 + TailwindCSS 4）、版本查询串缓存破坏与 11 个运行脚本语法校验；
- 统一 npm 命令体系：`npm run build`、`npm run build:bundle`、`npm run typecheck`、`npm test`。
