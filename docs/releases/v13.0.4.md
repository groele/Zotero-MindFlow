## 🌟 核心更新与修复细节

### 1. 全局快捷键指南面板（ShortcutsModal）全面校准
- 彻底移除历史遗留的非 Zotero 宿主项（如“Chrome 浏览器专属：快速摘录到导图”）；
- 严格对照 `App.tsx` 实际注册的键盘监听器，重构为三大逻辑分组：
  - **节点编辑与结构组织**：`Tab`（插入子节点）、`Enter`（下方同级）、`Shift+Enter`（上方同级）、`Space / 双击`（内联文字编辑）、`Enter (编辑中)`（提交保存）、`Esc (编辑中)`（取消恢复）、`Ctrl/Cmd + C`（复制分支）、`Ctrl/Cmd + V`（粘贴分支/图片）、`Ctrl/Cmd + D`（一键克隆副本）、`Delete / Backspace`（删除节点及子树）；
  - **画布漫游与视图控制**：方向键（空间穿梭导航）、`Shift + 鼠标拖拽`（框选多选）、`Ctrl/Cmd + 滚轮 / 双指捏合`（平滑缩放）、`空格 / 中键 + 拖拽`（平移画布）、`Ctrl/Cmd + 1`（全图居中自适应）、`Ctrl/Cmd + 0`（恢复 100% 缩放）、`F5 / Alt + P`（演示模式）、`F11`（全屏切换）；
  - **文档归档与系统操作**：`Ctrl/Cmd + S`（保存并立即归档至 Zotero 附件）、`Ctrl/Cmd + F`（全图即时搜索替换）、`Ctrl/Cmd + K`（快捷命令面板）、`Ctrl/Cmd + Z / Y`（撤销与重做）、`Ctrl/Cmd + ,`（打开偏好设置）、`?`（调出本指南）、`Esc`（退出弹窗/搜索/演示/禅模式）。

### 2. 设置界面与存储提示规范化
- 在 `SettingsModal.tsx` 中校正 WebDAV 凭据存储安全性提示，准确指明“连接凭据保存在宿主存储中；宿主环境不提供应用层加密”，消除遗留的非目标浏览器命名；
- 在 `storageService.ts` 中规范化注释为原子化存储写入保障。

### 3. 审查文档索引（docs/README.md）时序与证据完整性修复
- 纠正版本证据表中 `12.2.0` 错排在 `12.3.0` 前面的时序倒置缺陷，严格按倒序 SemVer 编排（`12.3.2` → `12.3.1` → `12.3.0` → `12.2.0`）；
- 补全版本证据表中遗漏的 `10.0.5` 历史条目（备份恢复版本校验、快照完整性与回滚输入保护）；
- 规范化全表发布状态枚举，统一历史版本标识；
- 整合中英文索引中针对 `10.0.2` 重复列出的条目，消弭重复条目。
