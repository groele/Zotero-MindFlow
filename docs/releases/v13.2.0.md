## 🛠️ 核心变更与改进明细

### 1. [宿主单文件巨石架构解耦] 4,816 行单文件全面模块化
- **领域职责解耦拆分**：将原 `chrome/content/scripts/index.js` 单文件拆分为 5 个结构清晰的子模块至 `chrome/content/scripts/modules/`：
  - `constants.js`：偏好键、存储文件名、默认配置与状态常量定义；
  - `storage.js`：本地磁盘工作区存储事务、原子落盘、备份与读回校验逻辑；
  - `item-pane.js`：ItemPane 侧边栏与条目卡片渲染、只读状态拦截与动作分发；
  - `note-sync.js`：导图附件与子笔记双向同步，含大纲导出与只读防护；
  - `bridge.js`：与前端页面（Webview/Iframe）的双向 postMessage 桥接路由与数据分发。
- **向后兼容门面（Facade）**：在 `index.js` 中内置轻量动态加载器 `loadHostModule()`（兼容 Gecko 宿主 `Services.scriptloader.loadSubScript` 与 Node.js vm 沙箱测试环境），对外暴露 `Zotero.MindFlow.Modules`，保留完全向后兼容的门面 API，确保第三方调用与历史行为零破坏。

### 2. [P0 数据安全加固] 导出大纲笔记与条目卡片只读深度守卫
- **导出大纲笔记（`exportAttachmentToNote`）只读守卫**：
  - 在获取 `parentItem = Zotero.Items.get(parentID)` 后，前置严格执行只读校验：
    `if (!parentItem || parentItem.deleted || (typeof parentItem.isEditable === 'function' && !parentItem.isEditable()))`；
  - 若条目无效、处于只读群组库（Group Library）或已被移入回收站（Trash），立即拒绝脏写入并抛出可追溯异常，遵循“失败不静默”原则保护用户文献库。
- **条目面板 ItemPane 卡片只读联动**：
  - 侧边栏渲染导图卡片时核对条目编辑权限；
  - 若条目只读，将「导出大纲笔记」按钮置为禁用状态（`button.disabled = true; button.setAttribute('aria-disabled', 'true');`），并在按钮悬浮提示与 aria-label 中明确标注文献只读不可导出。

### 3. [设置页面板 100% Fluent 本地化与 4.2 节对齐]
- **零硬编码文案驱动**：
  - `chrome/content/preferences.xhtml` 与 `chrome/content/scripts/preferences.js` 100% 接入 Fluent 本地化；
  - `locale/zh-CN/mindflow.ftl` 与 `locale/en-US/mindflow.ftl` 保持 184 项词条 1:1 严格对称，覆盖所有卡片分组、控件标题、帮助描述、快捷键与状态通知。
- **4.2 节三级层级与数学对齐规范落地**：
  - 卡片容器声明 `padding-inline: 16px` 标准网格；
  - 卡片顶部概述文字声明 `margin-inline-start: 0` 贴齐 16px 起始线；
  - 从属输入行（WebDAV 与快照配置项）附加 `.subordinate-row`，设置 `margin-inline-start: 24px`，严密对齐 40px 黄金对齐基准线。
- **主从开关依赖全生命周期守卫**：
  - 封装 `updateDependencies(doc)`，在 **① 面板初始化 (`init`)、② 用户交互 (`change`)、③ 外部配置变更 (`refreshControls`)、④ 恢复默认设置 (`reset`)** 四个时机全覆盖联动更新从属控件的 `disabled` / `aria-disabled` 属性与 `.is-disabled` 容器样式。
- **首组展开铁律**：
  - 全面板有且仅有第 1 张核心卡片（文献与工作台）设置 `open="open"` 默认展开，其余折叠卡片默认收起。

### 4. [更新源升级与全链路版本一致性]
- **更新源 SHA-512 安全升级**：
  - 更新源 `update.json` 与 `zotero/update.json` 中的 `update_hash` 升级为 `sha512:` 强哈希校验，构建工具 `release_package.py` 原生支持双哈希校验与自动同步。
- **全链路版本严格同步**：
  - `manifest.json`、`zotero/manifest.json`、`package.json`、`source/package.json`、`source/package-lock.json`、`docs/brand/product.json`、`chrome/content/index.html` 缓存参数及设置界面徽标全部严密对齐至 `13.2.0`。
