## 🌟 核心检验、问题诊断与优化细节

### 1. DOI 级联检索多字段独立穿透判定（Independent Multi-Field DOI Cascade Query Resolution）
- **问题诊断**：在 `searchItemByDoi` 中，原逻辑 `(item.getField('DOI') || item.getField('extra'))` 存在短路遮蔽漏洞：当本地文献条目 DOI 字段已存在旧的或不匹配数据时，即便其 Extra 字段中准确包含该条目规范 DOI，检索过滤也会直接跳过该条目；
- **优化实现**：在宿主 `chrome/content/scripts/index.js` 与前端 `source/src/services/zotero/zoteroBridge.ts` 中解耦为独立字段校验（`itemDoi === doi || extraDoi === doi || (extraVal && extraVal.toLowerCase().includes(doi))`），并在原生搜索条件命中及内存条目遍历中全面支持穿透匹配。

### 2. PDF 宿主阅读器异步调用与结果响应链路（Asynchronous Host PDF Open & Acknowledged Dispatch）
- **问题诊断**：原宿主 `MINDFLOW_OPEN_PDF` 特权消息未回传 `requestId`，缺少操作完成闭环；前端 `openItemPdfInZotero` 在消息派发后立即无条件返回 `true`，导致外部无法获知 PDF 是否真正成功打开或条目是否缺少附件；
- **优化实现**：在宿主 `index.js` 的 `openItemPdf` 完成后通过 `MINDFLOW_OPEN_PDF_RESULT` 回传状态与 `requestId`；前端建立带有 3 秒安全超时保护的 Promise 回调通道，精准返回 PDF 打开结果。

### 3. 独立窗口与弹出层宿主消息代理统一化（Unified Standalone Window & Popup Message Delegation）
- **问题诊断**：前端 `locateItemInZotero`、`openItemPdfInZotero`、`openExternalUrl`、`saveMindMapToZoteroAttachment` 及 `zoteroWorkspaceStorage` 原先硬编码仅向 `window.parent` 派发消息。当用户在独立窗口（`windowMode: 'window'`）或弹出工作台运行时，宿主窗口句柄位于 `window.opener`，导致特权消息完全丢失；
- **优化实现**：统一封装 `getHostWindow()` 智能判定工具（`window.parent !== window ? window.parent : window.opener`），使独立窗口工作台与内置标签页工作台获得完全等价的宿主联动通信能力。

### 4. 触控屏与触控板原生手势漫游与双指捏合平滑缩放（Native Touch Gestures & Pinch-to-Zoom）
- **优化实现**：
  - **主画布触控**：在 `Canvas.tsx` 中注册原生 `touchstart` / `touchmove` / `touchend` 监听器，实现单指平滑拖拽漫游视野与双指捏合（Pinch）平滑缩放（以双指中点为缩放锚点，严格约束在 0.05x 至 3.0x 范围）；
  - **离线导图 HTML 导出**：在 `exporter.ts` 的 `exportToInteractiveHTML` 脚本中嵌入双指触控距离计算（`Math.hypot`），支持将导出的思维导图直接在 iPad、Surface、平板或移动端触控屏上进行双指缩放与拖动交互。

### 5. Mermaid 思维导图通用语法导出（Mermaid Mindmap Export Interoperability）
- **优化实现**：
  - 新增 `generateMermaidMindmap` 与 `exportToMermaid`（`.mmd` 导出），采用 Mermaid 官方标准 `mindmap` 语法；
  - 自动清洗与转义双引号、反斜杠与换行符，严格维护 2 空格树层级缩进；
  - 工具栏导出菜单新增“Mermaid 语法 (.mmd) · 知识库通用”选项，导出的内容可无缝直接粘贴至 Obsidian、Logseq、Typora、Notion 以及 GitHub Markdown 中渲染。

### 6. 全键盘层级折叠与编辑快捷键体系完善（Keyboard-Driven Hierarchy & Editing Shortcuts）
- **优化实现**：
  - **即时折叠/展开**：选定节点时按下 `/` 键即可一键切换当前分支的折叠/展开（与右键菜单提示严格对齐）；
  - **多层级分支快速控制**：支持 `Alt+1`（仅显示 1 级主干）、`Alt+2`（展开至 2 级分支）、`Alt+3`（展开至 3 级分支）以及 `Alt+0` / `Alt+9`（展开全部层级）；
  - **顶栏层级折叠菜单扩展**：层级折叠菜单扩展增加“展开至 3 级分支”，并直观标注 `Alt+1` / `Alt+2` / `Alt+3` / `Alt+0` 快捷键徽章；
  - **常用文本重命名**：支持通用的 `F2` 快捷键进入节点编辑；
  - **全局搜索替换**：支持 `Ctrl+H` / `Cmd+H` 直接从画布唤起即时搜索与替换面板；
  - **快速取消选中**：按 `Esc` 键在未激活弹窗时可直接清除当前选中的节点；
  - **快捷键面板同步**：全键盘指南弹窗（`?` 键）完整收录以上快捷键。

### 7. 导航小地图连续按住拖拽同步平移（Minimap Continuous Pointer Drag-to-Pan）
- **优化实现**：在 `Minimap.tsx` 中利用 Pointer Events 与 `setPointerCapture`，用户不仅可以点击小地图跳转，还可按住鼠标左键或触控点在小地图上拖动，视口区域随之实时平滑连续平移，大幅提升在超大型复杂知识导图中的漫游定位效率。

### 8. 关联学术文献母篇快速触达卡片（Associated Literature Hub & Quick Jump）
- **优化实现**：
  - **顶栏下拉文献卡片**：顶栏“Zotero 学术文献联动”下拉菜单中新增专属文献条目卡片，显示母篇文献标题并提供一键“文库定位”和“打开 PDF”；
  - **空白画布右键菜单**：在关联文献的导图空白处右键呼出菜单时，支持一键定位母篇文献与打开全文 PDF；
  - **左侧工作台文档列表直达**：文档抽屉中的 Zotero 标识改为交互式按钮，点击即可直接跳转并定位该导图对应的本地文献条目。

### 9. 属性栏文献定位加载指示与智能浏览器回退（Property Sidebar Interactive State & Smart Fallback）
- **优化实现**：在 `PropertySidebar.tsx` 中引入 `isLocatingItem` 状态与旋转指示动效（`<Loader2 className="animate-spin" />`）；当本地查无此篇时，实时提供状态反馈并智能唤起系统默认浏览器访问对应 DOI 官方解析网址（`https://doi.org/...`）。
