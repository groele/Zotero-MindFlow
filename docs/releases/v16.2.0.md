# Zotero MindFlow 16.2.0

Zotero MindFlow 正式发布 **16.2.0** 版本，带来论文研读大模型重点分析指定章节、全新独立交互式提示词与功能预设工作台，以及丰富的学术场景内置提示词库。

## 🌟 核心新特性

1. **全文发送下的“重点分析指定章节”（Targeted Analysis Focus）**：
   - 支持在发送 PDF 全文或任意资料范围的前提下，让 AI 专门重点解构剖析特定论文章节与学术维度；
   - 包含 6 种明确的聚焦分析侧重：
     - 🔬 **方法与实验设计**：重点解构材料配比、实验流程、测量表征仪器与输入参数（温度、波长、电压、气氛等数值与单位），梳理对照组设计与复现细节；
     - 💡 **讨论与深度机理**：深挖作者对观测现象的因果归因、推导逻辑链条与竞争假说，严格区分直接证据与推断；
     - 📊 **数据与关键发现**：提炼直接观测现象、定量指标数值（含误差区间）与相对基准（Baseline）的提升幅度；
     - 🎯 **结论与学术贡献**：聚焦文末核心结论、对核心科学问题的明确回应、实际应用启示、工作局限性（Limitations）与未来验证；
     - 📝 **摘要与核心主旨**：极速掌握核心科学痛点、创新方案与最高层级主张；
     - 🌟 **全文综合研读**：系统平衡覆盖背景、体系、方法、结果、机理与结论；
   - 宿主分析逻辑中精准注入专属学术引导词，确保大模型优先将分析权重与展开层级分配至所选重点章节。

2. **独立交互式“提示词与功能预设工作台”（Prompt Presets Workbench）**：
   - 提供专属的可编辑模态视窗（`ResearchPromptEditorModal`），彻底解决传统下拉菜单切换繁琐、不直观的痛点；
   - **左侧功能分类直观切换列表**：内置 8 组学术功能预设卡片 + 用户自定义预设列表，1-Click 快速载入；
   - **右侧富交互提示词编辑器**：支持多行提示词自由编辑与扩展（0～6000 字符实时计数）；
   - **一键快捷插入学术指令标签**：提供“+ 提取定量数值与单位”、“+ 重点辨析因果机理”、“+ 突出对照组实验设计”、“+ 区分作者解释与直接证据”、“+ 强调局限性与未解问题”、“+ 规范学术中文术语”等快捷芯片；
   - **预设管理完整闭环**：支持“另存为新预设”、“更新所选预设”、“设为默认”、“删除自定义预设”与“绑定导图主题外观”。

3. **架构守卫与工程质量红线**：
   - 全库 185 个 TypeScript/TSX 源码文件 100% 恪守单文件 360 行上限约束（0 违规、0 债务）；
   - 全链路版本号严格对齐 `16.2.0`，中英双语 Fluent 目录 174 键完全对称。

4. **完整工程验证**：
   - 宿主与前端 TypeScript 类型检查 0 报错；
   - 16 项架构守卫、116 项宿主测试、40 项导图逻辑 + 8 项预设工作台 + 23 项数据完整性测试全部 PASS（共 71 项前端测试，0 失败）。
