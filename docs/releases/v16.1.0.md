# Zotero MindFlow 16.1.0

Zotero MindFlow 正式发布 **16.1.0** 版本，将“AI 解析论文并生成导图”提升为画布顶栏独立功能，全面升级科研论文大模型精读的易用性与响应式体验。

## 🌟 核心升级与特性

1. **AI 导图解析功能独立至工具栏**：
   - 将原嵌套在 `Zotero ▾` 下拉菜单中的“AI 解析论文并生成导图”提取为工具栏第一级独立按钮；
   - 采用醒目的紫罗兰主题配色（`bg-violet-50` / `text-violet-700`），悬停显示研究问题、体系、证据、意义与局限完整解析提示。
2. **多端自适应响应式布局**：
   - 大屏全量展示 `AI 解析论文并生成导图`；
   - 常见桌面与标准视窗自适应紧凑展示 `AI 解析导图`；
   - 窄边栏模式自动收拢为图标按钮，保障工具栏布局整洁不折行。
3. **动态状态指示与防护机制**：
   - 分析进行中图标旋转并提示 `正在解析…`，防止重复提交；
   - 完善非 Zotero 环境下的友好前置引导，保留 `Zotero ▾` 菜单双入口。
4. **架构守护与代码质量红线**：
   - 100% 恪守单文件 360 行上限约束（0 债务）；
   - 全链路版本号严格对齐，中英双语 Fluent 目录对称。
5. **完整自动化测试验证**：
   - 架构守卫、宿主行为测试、XPI 构建测试及前端测试全部通过。
