# Zotero MindFlow 12.6.10

## 中文

- 优化文献侧栏刷新机制，增加 120ms 防抖调度与变更范围过滤，销毁或换选时自动清理定时器，避免高频并发重绘。
- 引入条目签名比对，条目元数据与附件未变动时跳过无谓 DOM 重绘，降低主界面负载。
- 规范侧栏视觉与字号排版：次要文本与说明对齐为 13px（行高 1.6），按钮统一为 14px；空状态使用单一强调色主按钮，已有导图后次要操作统一采用原生中性前景（`currentColor`），移除多色悬浮竞争。
- 增强侧栏中英双语国际化支持与回退能力。
- 包含 12.6.9 补丁：强化侧栏打开 PDF 逻辑，支持显式窗口上下文与阅读器异步失败回退。

## English

- Optimize the literature sidebar refresh pipeline with 120ms debouncing and scoped item filtering, cleaning up pending timers on teardown and selection changes.
- Add signature caching to skip redundant DOM replacements when parent metadata and attachments remain unchanged.
- Standardize sidebar typography and visual hierarchy: secondary copy and labels align to 13px (1.6 line-height) and action buttons to 14px; solid accent styling is reserved for the initial empty-state call-to-action, while secondary actions use neutral foregrounds (`currentColor`).
- Enhance English/Chinese dual-language fallback support across sidebar actions.
- Incorporate v12.6.9 improvements: harden PDF opening with explicit window context and asynchronous reader error fallbacks.
