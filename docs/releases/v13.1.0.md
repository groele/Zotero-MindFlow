## 🌟 核心现代化改造细节

### 1. 工程生命周期标准化（Root package.json & Unified Lifecycle）
- 确立统一根级 `package.json`（v13.1.0），收敛 `test`、`build`、`typecheck`、`test:host`、`test:frontend`、`test:package` 与 `test:tags` 脚本命令；
- 对齐全系自动化测试流程，实现宿主与前端统一流水线。

### 2. 设置界面 4.2 三级层级与边缘距离标准规范深度对齐（Section 4.2 Grid Alignment）
- **16px 绝对基准线**：设置面板主容器内边距规范化为 `padding: 12px 16px 28px;`，卡片内边距声明 `padding: 12px 16px;` 与 `padding: 8px 16px 16px;`；
- **40px 黄金对齐基准线**：次级描述文字、从属复选框与单选组通过 `margin-inline-start: 24px` 严格与上方主选项文字标签保持 40px 纵向垂直对齐；
- **排版字号基准**：主标题 18px、分组标题 14px（600 字重）、说明文字 13px（次级前景灰），表单输入框与下拉选择框自然继承 14px 系统字体，杜绝布局溢出与字体缩放伪对齐；
- **版本与发行卡片**：发布说明、构建日期、XPI 下载和仓库链接分行清楚展示，从真实权威元数据中动态取值。

### 3. 条目面板与归档写入只读防护机制（Section 5.4 Read-only Guard）
- **条目信息面板防护**：在 `chrome/content/scripts/index.js` 的 `onAsyncRender` 中深度集成 `item.isEditable()` 原生安全检查。当用户浏览只读群组文献（Group Library）或回收站（Trash）条目时：
  - 自动渲染只读状态徽标（`mf-status-readonly`）；
  - 主创建按钮与模板选择控件平滑降级为只读禁用状态（`disabled: true`），并展示本地化悬浮防护提示；
- **导图归档写入保护**：在 `saveMindMapToItem` / `_saveMindMapToItem` 中针对目标文献及群组库执行 `isItemEditable` 与 `library.editable` 双重熔断拦截，严禁对只读文献触发脏写入或非法创建附件；
- **条目序列化自愈**：在 `serializeZoteroItem` 中注入 `isEditable` 安全标识，使前端工作台画布与大纲即时感知只读状态。

### 4. 自动化测试套件深度扩展（101 Host Tests & 224+ Total Passed）

  - `item-pane onRender` 只读徽章与控件禁用 DOM 渲染验证；
- 全库通过 101 项宿主沙箱测试、8 项发布包验证测试、标签语法自检、54 项前端数据链测试、39 项核心逻辑测试、7 项科研预设测试与 23 项数据完整性测试，全量 224+ 项测试 100% 通过。
