# Zotero MindFlow 13.2.1

发布日期 / Release date: 2026-11-04 · Patch release

## 修复与完善

- 修复带关系线的正常导图无法保存：统一编辑器、工作区存储和附件归档的数据校验契约。
- 修复关闭/退出等待遗漏真实写入队列、关闭保存失败不能重试的问题；等待期间追加的保存和归档任务也纳入处理。
- 加固大纲导出：异步读取后重新核验只读、回收站、父条目和插件生命周期；停用时关闭插件工作台并清理监听器。
- 点击 MindFlow 侧栏入口时展开目标卡片，初始化保留原生折叠偏好；保存提示区分“待保存”和“本地已保存、归档中”。
- 移除部分重复实现，增加独立的关闭协调与侧栏可见性模块；设置模板静态文案通过 Fluent 加载。

## Fixes and improvements

- Fix saving maps with relationship edges by sharing the editor's document contract across workspace storage, outlines and attachments.
- Drain the actual persistence queues on close/quit, include work appended while draining, and allow failed close snapshots to retry.
- Recheck outline-export permissions, Trash state, parent identity and lifecycle after asynchronous reads; clean up owned workspaces and listeners on disable.
- Expand the target section on explicit sidenav navigation while retaining native collapse preferences; distinguish pending edits from local saves awaiting archive.
- Remove duplicate persistence implementations, isolate close coordination and section visibility, and load static preference text through Fluent.

- TypeScript check, production build and runtime syntax checks passed.
- 116/116 simulated host tests and 10/10 package-policy tests passed; all five frontend test programs and tag-policy self-tests passed.
- Zotero 10.0.7 in an isolated profile: 51/51 native checks and 3/3 process-restart checks passed.
- Reproducible XPI payload verification; both update feeds use SHA-512.

兼容声明为 Zotero 10.0–12.*。本轮实际宿主验证为 Zotero 10.0.7；未安装用户主 profile，Zotero 11/12、跨平台、完整亮暗主题及真实外部服务验收仍待完成。模块拆分仍在逐步推进。

Declared compatibility: Zotero 10.0–12.*. Native validation covers Zotero 10.0.7. Main-profile installation, Zotero 11/12, cross-platform, complete light/dark acceptance and live external-service validation remain unverified. Architecture decomposition remains incremental.
