## 🌟 核心更新亮点

### 1. 宿主兼容版本上限全面跃升至 `12.*`
- 在 `manifest.json`、`zotero/manifest.json`、`update.json` 与 `zotero/update.json` 中全面双写 `strict_min_version: 10.0` 与 `strict_max_version: 12.*`；
- 兼顾 Zotero 10.x 稳定版，并全面无缝支持未来的 Zotero 12 系列。

### 2. 设置系统 Schema 强类型校验与清洗（P1-04）
- 在 `SettingsService` 中引入 `sanitizeSettings` 验证过滤引擎；
- 严格校验 `defaultLayout`、`canvasBackground`、`curveStyle`、`toolbarPosition`、`workbenchDockPosition`、`zoteroWindowMode` 等枚举值；
- 增加数值与区间安全钳位：`maxSnapshotsPerDoc` 约束在 10~50、`autoSnapshotIntervalMinutes` 约束在 1~120、`zoomStep` 约束在 0.05~0.5、`aiMaxPdfPages` 必须有效；
- 彻底防止非法或损坏数据导致工作台初始化奔溃。

### 3. 工作区备份版本兼容性门禁与研读预设随备份迁移（P2-01 & P2-08）
- **备份模式升级**：工作区备份引入 `schemaVersion: 2`；
- **版本门禁安全防护**：严格校验 `exportedAt` 时间戳与版本号，当遇到未来更高主版本（如 > 13）的备份文件时明确拒绝并提示用户升级，防止破坏性反序列化；
- **研读预设（Research Presets）随备份迁移**：导出备份时完整打包用户自定义研读预设，恢复工作区时自动安全合并，填补了此前研读预设无法随工作区迁移的空缺。

### 4. 全导出格式（SVG / PNG / Interactive HTML）微元渲染对齐
- **离线交互式 HTML 导出微元补齐**：补齐非 readingStyle 节点的任务状态图标（已完成绿标、进行中蓝标、待办灰标）与删除线透明度样式，消除与 SVG、PNG 导出的视觉差异；
- **SVG / PNG 导出任务微元与删除线强化**：修正测量宽度与绘制对齐，消除节点右侧预留空白。

### 5. 文献侧栏 ItemPane 暗色模式与字号设计规范对齐
- 侧栏 ItemPane 全面采用 `color-mix(in srgb, currentColor ...)` 与宿主原生 CSS 变量，彻底移除硬编码的白底黑字；
- 补齐 Fluent 本地化缺失键，卡片文字与表单控件字号对齐至 12px-13px。
