## 🌟 核心更新与逻辑优化细节

### 1. 导图节点 DOI 按钮一键跳转与数据库条目精确定位
- 在导图节点卡片中，当节点链接或正文包含 DOI（例如 `DOI: 10.1038/s41563-022-01459-z`）时，点击卡片右上角的外链按钮可直接在 Zotero 本地数据库中定位并高亮对应文献条目，自动切换至 Zotero 主文献库标签页；
- 若本地文献库未收录该 DOI 条目，或用户按住 `Ctrl` / `Cmd` / `Alt` 快捷键点击，系统将自动无缝回退至调用系统默认浏览器打开该文献的 DOI 官方主页；
- 悬停浮层展示清晰友好的引导提示：“在 Zotero 数据库中定位对应条目（未找到或按住 Ctrl 点击打开网页）”。

### 2. 多格式 DOI 智能清洗与标准化（DOI Normalization）
- 增强 `extractDoi` 与 `normalizeDOI` 算法，全面兼容裸 DOI（`10.xxxx/...`）、`doi:` 前缀、`https://doi.org/...` 网址以及正文混排的多行文字提取；
- 完善括号配对剥离与 Unicode 零宽字符过滤，确保 DOI 格式无误；
- `safeExternalUrl` 自动将裸 DOI 规范化为 `https://doi.org/...` 安全链接。

### 3. 宿主与工作台双向跨进程安全通信联动
- 宿主 `chrome/content/scripts/index.js` 扩展 `MINDFLOW_LOCATE_ITEM` 指令，支持通过条目 key、zotero URI 或 DOI 在用户库及群组库中并发检索条目，并通过 `win.ZoteroPane.selectItem(item.id)` 实时高亮选中；
- 新增 `MINDFLOW_LAUNCH_URL` 消息处理器，安全调度 `Zotero.launchURL(url)`，确保外部链接可在原生操作系统默认浏览器中准确打开。

### 4. 节点右键上下文菜单联动优化
- 节点右键菜单在检测到节点包含 DOI 或引用文本时，智能激活“在文献库中定位条目”与“打开对应文献 PDF”快捷操作，实现大纲与知识图谱对文献库的双向无缝衔接。
