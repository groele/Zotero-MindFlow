# Zotero MindFlow 14.0.5

架构治理与模块拆分版本。兼容声明 Zotero 10.0 – 12.*（开发基准 Zotero 10；11/12 为前瞻声明，未做实机验证）。

## 本版改动

- **规范红线清零**：替换 Zotero 废弃的单数集合选择接口与布尔属性字符串写法；菜单文案改为 Fluent 本地化；bootstrap 补齐本地化包刷新与卸载清理。
- **tsconfig 黄金标准**：启用 `strict` / `noImplicitAny` / `isolatedModules` / `verbatimModuleSyntax` / ES2023 / `noEmit`，并把严格类型错误收敛到 0。
- **11 项架构守卫**：接入 `npm test` 与构建链，覆盖 §5.9 360 行冻结基线、基线有效性、§5.3 废弃接口、§4.1 偏好键覆盖、§4.2 16/24px 网格、§5.2 导出名与常量漂移、§3 Fluent 对称与命名、§6 版本一致、§9.1 双更新源一致。
- **冻结超限模块 16 → 10**：按职责分层拆分 `App` 之外的领域模块与设置页控制器，新增模块全部 ≤360 行；`test-host.mjs` 1992 行拆为共享夹具 + 7 个分片；设置页网格改为显式逻辑属性声明（视觉等价）。
- **发布闭环**：11 个版本字段一致，两个更新源逐字节相同，`update_hash` 为 `sha512:` 全量哈希且指向本 Release 资产。

## 已知边界

- 真实 Zotero 宿主安装、亮暗主题与窄窗 computed style、Zotero 11/12 实机与多窗口回归未执行；静态断言和单元测试不替代原生验收。
- 仍有 10 个历史超 360 行模块处于冻结禁增长状态（以 React 组件为主），后续逐轮拆分。
- 运行时 JS 与 TS 契约层仍是双轨维护，靠守卫拦截导出名与常量漂移，尚未改为生成链。

## 安装

下载下方 `zotero-mindflow-14.0.5.xpi`，在 Zotero 中通过「工具 → 附加组件 → 从文件安装」加载。自动更新由仓库内的更新源提供。
