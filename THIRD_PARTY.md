# Third-party rights and provenance

Zotero MindFlow is described as an independently maintained plugin in its README and is currently licensed under [MIT](LICENSE). The README mentions an **optional** integration with an externally installed `llm-for-zotero` runtime. An optional runtime integration does not automatically mean that its code is copied or relicensed here.

## Verification required
- [ ] Confirm from source/package history whether any external Zotero plugin code, UI component, icon, font, diagram engine or template was copied/adapted.
- [ ] Record full source URL, exact revision, copyright, license, distribution path and required attribution for any reused material.
- [ ] Examine the final XPI and embedded/offline HTML exports for vendored scripts, styles, graphics and licenses; include notices in output where applicable.
- [ ] Review AI runtime/API integrations separately: dependencies, service terms, prompt/user content handling and the status of generated assets.
- [ ] Verify build-time dependency licenses and whether build tools or runtime components are actually bundled.
- [ ] Preserve upstream copyright notices when third-party material exists.

README statements that the project is not based on a single external map plugin do not demonstrate that every asset is independently authored. Avoid applying the MIT label to third-party materials without verification.
